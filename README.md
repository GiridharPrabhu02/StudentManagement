
Hello! This is my **console-based non-persistent Student Management System written in C**.

## A. Built With

* **C**


## B. How to Run:

### 1. Compile

With GCC installed, compile the program using:

```bash
gcc StudentManagement.c -o StudentManagement
```

### 2. Windows

```bash
StudentManagement.exe
```

### 3. Linux

```bash
./StudentManagement
```


## C. Program Overview:

* The program allows users to manage student records through a menu-driven interface.
* A maximum of **100 students** can be stored during one program run.
* Each student record contains an **ID, name, branch, and marks**.
* Students can be added, viewed, searched, updated, and deleted.
* Students can be searched using their **name or ID**.
* Student data is stored in memory using **dynamic memory allocation**.
* The current version is **non-persistent**, so all student data is lost when the program is closed.

## E. Features & Usage:

* Add a new student by entering their ID, name, branch, and marks.
* View all currently stored students.
* Search for a student using their name or ID.
* Update the branch or marks of an existing student.
* Delete a student using their ID.
* The program prevents adding more than **100 students**.
